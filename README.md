# DNB Hub – Server (Backend)

## Description

This repository contains the **backend REST API** for the DNB Hub application. The API is built using **Node.js, Express and MongoDB**, and provides authentication and CRUD operations for events, artists and venues.

---

## Features

- RESTful API design
- JWT-based authentication
- Password hashing with bcrypt
- Full CRUD for events
- Create and read artists and venues
- Authorization (only owners can edit/delete their content)
- Centralized error handling
- Input validation with Mongoose
